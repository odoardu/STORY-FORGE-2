# LPZ Liquid Glass Layout - Figma

Este plugin cria o layout do Story Maker em camadas editaveis no Figma.

## Como importar

1. Abra o Figma Desktop.
2. Va em `Plugins` > `Development` > `Import plugin from manifest...`.
3. Selecione este arquivo:

`C:\Users\Eduardo\Desktop\LP_ZERO\figma-lpz-liquid-glass\manifest.json`

4. Rode `Plugins` > `Development` > `LPZ Liquid Glass Layout`.

O plugin cria um frame chamado `LPZ Liquid Glass Story Maker`, com dock, painel, preview vertical, barra superior e player editaveis.
