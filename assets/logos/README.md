# Logos do StoryForge

Coloque aqui as logos que voce quiser aplicar no rodape do story.

Formatos aceitos pela lista/catalogo do editor:

- `.svg` preferido para logos vetorizadas
- `.png` com fundo transparente

Recomendacao para vetorizar/exportar:

- Use SVG simples com `viewBox`
- Evite imagens linkadas dentro do SVG
- Evite fundo branco/preto no arquivo
- Prefira logo branca ou clara para aparecer no fundo preto
- Para PNG, exporte com pelo menos 1000 px de largura
- O nome do arquivo pode ser qualquer um, com espacos ou acentos
- O que importa e a extensao final ser `.svg` ou `.png`

Depois de adicionar arquivos aqui, abra o painel `Logo` no editor e clique em `Atualizar`.
